A practice project exploring web accessibility, including semantic HTML, keyboard navigation, accessible forms and readable page layouts.
# Web Accessibility

## About This Project

This project is part of my software and web development course. I'm learning about web accessibility and how to make websites easier for different people to use.

I'm using this project to practise building pages that are clear, easy to navigate and usable by people who may rely on a keyboard, screen reader or other assistive technology.

## What I'm Working On

- **Semantic HTML** – using elements such as `header`, `nav`, `main` and `footer` where appropriate.
- **Image alt text** – adding useful descriptions to images where needed.
- **Keyboard navigation** – making sure interactive elements can be accessed without a mouse.
- **Forms and labels** – providing clear labels and instructions for form fields.
- **Colour contrast** – choosing text and background colours that are easy to distinguish.
- **Focus indicators** – making it clear which element is selected when navigating with a keyboard.
- **Headings and structure** – organising content so it's easier to understand and navigate.
- **Accessible links and buttons** – using clear text that explains what each element does.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the chance to understand why accessibility matters when building websites. I'm learning how small decisions in HTML and CSS can make a difference to how people navigate and interact with a page.

I'm also learning that accessibility isn't just about how a website looks. It needs to work properly for people using different devices and assistive technologies too.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Try navigating the page using only your keyboard.
4. Check the page layout, text contrast, headings and form labels.
